Security Writeups

Web application penetration testing writeups, documenting hands-on vulnerability testing and exploitation.

Each writeup follows a consistent structure: **hypothesis → testing steps → request/response evidence → payload → root cause**, aimed at showing not just that a vulnerability was found, but how it was found and why it works.

About Me

Aspiring web application penetration tester based in Nigeria. Testing methodology follows OWASP Top 10 categories, using Burp Suite to identify and validate vulnerabilities through manual analysis of application behavior.

Tools Used

- Manual testing / OWASP Top 10 methodology
